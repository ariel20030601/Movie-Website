# Radical Movie Reviews
The main objective of this website is to provide a simple, clean and easy method for users to view different movies that are available as well as their rating and description, while also allowing users to leave their personal reviews and ratings as well.
# Description
Radical Movie Reviews is a web-based application that allows users to manage a movie database through a simple and interactive interface. The site enables users to add new movies, edit existing entries, and delete them as needed. It includes dynamic features such as expandable sections and inline edit forms to keep the interface clean and responsive.

The application supports user roles, with certain actions available only to the admin user. When a movie is successfully added or an error occurs, a notification box drops from the top of the screen to inform the user. The backend is integrated with a MySQL database, which is automatically created if it doesn't exist. This platform is ideal for managing small to mid-sized movie collections and serves well as a learning project, helping me learn about NodeJS and MySQL mainly.

# Tools
This application was developped using HTML, Taildwind-CSS and JS for the front-end portion, NodeJS for the back-end as well as MySQL for the database.
